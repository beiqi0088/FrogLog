## 4. 建议节奏

**第一轮（先把「不丢数据」和「日常好用」补齐）**
`A1 备份回滚` ✅ → `A4 朗读` → `A3 备注` → `A2 颜色/标星`

**第二轮（内容形态）**
`B1 图片卡` → `B2 遮挡` → `B3 填空`

**第三轮（规模与生态）**
`B4 Excel 导入` → `C1 apkg 导入` → `C5 增量同步`

理由：A1 直接覆盖这次「密钥被覆盖/数据被换掉」的事故类型；A4/B1/B2 是 Anymo 用户最能感知的差异；B4/C1 决定「能不能一次性把资料搬进来」。
