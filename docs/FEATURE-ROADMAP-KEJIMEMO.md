## 2. 浮卡现状（已有）

知识域 → 圆桌 → 卡包 → 卡组；富文本编辑器（挖空 / 墨线 / 加粗 / 颜色 / 背景 / 下划线 / 图片 / 清除格式 + 实时预览）；三题型复习 + FSRS-6 调度 + 卡包选项；撤销 / 暂停 / 搁置 / leech；搜索（`tag:` `is:` `deck:`）；批量操作；回顾抽样；洞察六维 + 28 天热力 + 准确率；8 套主题；7 套卡片皮肤；docx 导入；浮墨记录 / 批量拆卡；同步（局域网 / WebDAV / S3）；备份与回滚（每日 / 手动 / 回滚前快照）；编辑页/浏览页新建卡片。

**明确没有**：回收站（删除是硬删）、背面提示、卡片批注、双链/引用、图片挖空、挖空分组与开关模式、字号/卡片比例、排序方式、提前复习/改到期日、四态标记、学情预估、导出 PDF/图片、音频块、LaTeX、OCR 导入。

## 3. 可加功能（按价值 ÷ 成本排序）

### A 档：小改动，直接补短板

| # | 功能 | 刻记的做法 | 浮卡的落点 | 工作量 |
|---|---|---|---|---|
| A1 | **回收站** | 删除进回收站，可恢复/清空 | `core.Store` 给卡片加 `deleted_at`；记忆页底部「回收站」入口；恢复/彻底删除 | ~250 行 |
| A2 | **背面提示** | 卡包/卡片设置「背面提示」，答案卡下方显示 | 卡片加 `hint` 字段；编辑页加一行；复习背面渲染 | ~80 行 |
| A3 | **卡片批注** | 卡片详情里的「批注」记录思考，可清空 | 卡片加 `notes[]`；复习页 ⋯ →「批注」弹窗；列表用 📝 标记 | ~120 行 |
| A4 | **提前复习 / 改到期日** | 复习页可提前复习未到时间的卡、改下次复习日期 | 复习页 ⋯ →「改到期日」小日历；`due` 直接改 | ~100 行 |
| A5 | **字号 / 卡片比例** | 正/背面字号、卡片比例（3:4 等） | 设置 →「卡片显示」：字号档位 + 卡片宽度比例，`card_render` 读取 | ~120 行 |

| # | 功能 | 刻记的做法 | 浮卡的落点 | 工作量 |

## 4. 建议顺序

1. **A1 回收站** —— 现在删除卡组/卡片是不可恢复的，这是最该补的安全性缺口（和之前做的备份回滚是一套）。
2. **A2 背面提示 + A3 批注** —— 复习体验，一天能做完。
3. **A4 提前复习/改到期日 + A5 字号** —— 让调度和阅读都能顺手调。
4. **B1 图片挖空** —— 挖空是我们已经做透的差异点，补上图片维度就能明显区别于普通背单词 App。
5. **B4 导出 PDF 图片** —— 分享/打印场景。
