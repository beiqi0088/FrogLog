# 全站性能体检与修复（2026-11-22）

方法：离屏 Qt（`QT_QPA_PLATFORM=offscreen`）+ 真实数据副本，
每步 `processEvents()` 后补一次 `sendPostedEvents(None, DeferredDelete)`
（否则旧页面不会被回收，测出来的耗时会被放大好几倍——第一次量主题切换的 650ms 就是这么来的）。

脚本都在 `_scratch/`：`perf_audit.py`（逐页/逐动作）、`prof_*.py`（单项拆解）、
`perf_saves.py`（落盘次数）、`perf_scroll.py`（滚动）。

## 修了什么

| # | 问题 | 原因 | 修复 | 效果 |
|---|---|---|---|---|
| 1 | **切主题卡 0.6–0.8 秒** | `resolve_family()` 每次都 `QFontDatabase.families()` 枚举系统字体 | 结果缓存（`_FAMILY_CACHE`） | 650ms → ~50ms |
| 2 | **点卡组行开学习页慢** | `_open_group()` 先 `build()` 整个卡包页，随即被学习页替换 | 学习模式直接开复习；没卡可学才补 build | 36ms → ~19ms |
| 3 | **冷启动第一次进学习页慢** | 首次字体/样式/文本排版开销 | 启动 2.2s 后后台预热一张复习页（用完即删） | 首次 66ms → ~23ms |
| 4 | **翻答案 / 点选项整页重建** | `_reveal/_pick/_submit` 都调 `render()` | 顶栏按卡缓存；翻面只重建卡片区 + 切换底部按钮（预先建好两套，切显示） | 翻面 50ms → ~20ms |
| 5 | **评分一次写两次盘** | `save()` + `bump_deck_stats()` 各写一次 | `bump_deck_stats(..., persist=False)`、`bury_siblings(..., persist=False)`，评分结束统一写一次 | 少一次 181KB JSON 落盘 |
| 6 | 点挖空 / home 键 / 模式按钮卡顿（上一轮） | 每次点击整页 `render()` | 原位改颜色 + 横线矩形缓存 + 只画可见区 | 点击 ~4ms |

## 现在各处的耗时（离屏，真机会大 2–4 倍）

| 动作 | 耗时 |
|---|---|
| 切主题 | ~50ms |
| 页面构建（今日/记忆/征途/洞察/卡包/卡组/设置/调度/编辑器） | 12–35ms |
| 开学习页（预热后） | ~20–40ms |
| 翻答案 | ~20ms |
| 评分一张（问答卡） | ~15–18ms |
| 评分一张（单选/多选卡） | ~35–45ms |
| 撤销一步 | ~40ms（等价于重建上一张卡） |
| 复习页滚动 | 0–10ms/格 |

## 还剩的瓶颈（已知，未修）

1. **单选/多选卡比问答卡慢 ~25ms**：选项行（`OptionPill`）各带一份 `setStyleSheet`，
   新控件首次显示时要参与全局样式匹配。彻底解决要把选项行改成纯 `paintEvent` 绘制
   （不再用 QLabel + 局部样式表），改动视觉风险较高，暂未做。
2. **每张卡都是"销毁旧控件 + 新建控件"**：Qt 新控件首次 polish/paint 有固定开销。
   要再快需要把卡片视图做成"复用控件、只换文字"（类似 RecyclerView），是一次较大的重构。
3. **撤销**：走的是完整 `render()`，因为要回到上一张卡；可优化的空间同上。
4. 页面构建 20–35ms：主要花在控件创建 + 全局样式匹配，属于当前架构的正常水平。

## 结论

高频路径（点挖空、home、翻答案、点选项、评分、开学习页、点卡组行、切主题）都已经
不再有"整页重建"级别的卡顿；剩余开销集中在 Qt 自身对新控件的样式匹配与排版上，
属于"每张卡 15–45ms"的量级，要再往下压需要改造卡片渲染的复用机制。

## 2026-11-23 续修：卡组点击 / 评分

| 问题 | 原因 | 修复 | 效果 |
|---|---|---|---|
| 从卡包页点卡组进学习页卡 | 每次打开都新建 ReviewPage + 销毁旧页（整棵树重建、重新布局） | 复习页改成常驻单例：切走不销毁，回来只换 `setCurrentWidget`；启动预热时直接预建它 | 首次 62ms → **19.5ms**；再进 61ms → **12–13ms** |
| 退出复习后偶尔莫名回到「今日」 | 常驻页残留的 80ms 重绘定时器在 session 清空后调 `render()`，旧逻辑会 `show_page("today")` | `render()` 无 session 直接返回；`exit_review()` 停掉重绘定时器 | 竞态消除（连跑 6 次稳定） |
| 点评分按钮卡（30–90ms） | 每张卡都重建底部操作条（4 个评分按钮 + 计数胶囊 + ⋯），选项行悬停反复编译局部样式表 | 顶栏/底栏只建一次，换卡只更新文字；选项行改成 `paintEvent` 自绘 | 评分 **8–18ms**（单选/多选/问答一致） |
