怎么修改这份设计稿

① 换配色 / 圆角 / 字号

只改文件顶部 :root 里的变量。深色模式在 html[data-theme="dark"] 里， 两套变量一一对应。
  • --bg 纸白背景 · --surface 卡片 · --line 分隔线
  • --primary 墨绿主色 · --accent 赭石强调色
  • --r-sm / --r-md / --r-lg 三档圆角

② 改页面内容

DATA 对象是唯一数据源：记忆库、卡片、预测值、洞察指标都在里面。 改数字或中文，页面会自动重排。

③ 改结构

每个页面是一个函数：screenToday()、screenLibrary()、 screenReview()、screenPlan()、screenInsights()、 screenSettings()、screenDeck()、screenConsent()。 函数返回 HTML 字符串，直接增删标签即可。

④ 看单页大图

地址后面加 ?only=today（today / library / deck / review / plan / insights / settings / consent），会只渲染这一屏，方便截图或单独调。

配色与文案来自 APK 反编译：f3.a 调色板、 d3.r 记忆库色板、strings-zh.txt 的 375 条中文。
