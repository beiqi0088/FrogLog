这次合并进来的（来自桌面版「浮卡」）

  • 7 套卡片皮肤：天蓝薰衣 / 弥散雾影 / 淡粉紫橙 / 粉彩撞色 / 绿韵黄调 / 豆沙绿语 / 青柠薄荷
  • 3 种题型：问答、单选、多选（带选项、正误态、解析）
  • 浮墨速记：一个输入框，--- 拆正反
  • 批量拆卡：粘贴序号行 → 自动识别题型 → 预览 → 导入
  • 知识域：学习 / 工作 / 生活，作为记忆库的第一层筛选

没搬过来的（桌面端特有，手机上会过重）

  • 「圆桌 → 铁盒 → 卡包 → 卡组」四级嵌套 → 压成「知识域 → 卡包 → 卡组」
  • Logseq 式树状笔记 / 双链 / 反链
  • 桌面端的拖拽、右键菜单、批量勾选

改法

配色在 :root；卡片皮肤在 .tpl-* 一组类；内容在 D 对象； 每个页面一个 sXxx() 函数。单屏预览加 ?only=reviewqa。
